# Lab001 — Казино (рулетка)

C++20, DDD-архитектура: европейская рулетка (single zero), боты (martingale, red-constant), человек в интерактивном режиме, SVG-графики балансов.

## Сборка

Требуется: CMake ≥ 3.20, GNU GCC (или Clang) с поддержкой C++20.

```bash
cmake -S . -B build
cmake --build build
```

Бинарник: `build/lab001`.

## Запуск

```bash
./build/lab001
```

При запуске спросит, кто играет:

| Символ | Режим |
|--------|-------|
| `б` / `Б` / `b` / `B` | Боты (симуляция, 100 раундов) |
| `ч` / `Ч` / `h` / `H` | Человек (интерактивная игра) |

### Режим ботов

Симуляция двух ботов против стола:
- **Осторожный-Ред** — ставит на красное фиксированной суммой
- **Мартингейл-Блэк** — удваивает ставку на чёрное после проигрыша

По итогам генерируется `balances_chart.svg` (в рабочей директории запуска).

### Режим человека

Ввод: лимиты стола → касса → баланс игрока → тип ставки (цвет/число) → параметры ставки → спин.

## Тесты

```bash
cmake --build build --target run_all_tests
cd build && ctest --output-on-failure
```

## Покрытие

Сборка уже включает флаг `--coverage` (gcov). Чтобы получить отчёты:

```bash
# 1. Прогнать тесты (собирают .gcda)
cmake --build build --target run_all_tests
cd build && ctest

# 2. Сгенерировать .gcov-файлы в build/coverage/
cd build
cmake --build . --target coverage

# 3. Отчёты
ls build/coverage/*.gcov
```

Очистка:

```bash
cmake --build build --target coverage_clean
```

## SVG-график

График балансов ботов и стола по раундам генерируется автоматически при завершении `bot_play()`:

```bash
cd build && ./lab001
# ввод: б
# → balances_chart.svg в CWD
```

Открыть в любом браузере или SVG-просмотрщике.
